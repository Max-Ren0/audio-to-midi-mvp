# Audio to MIDI MVP

将本地音频或视频转换为可继续编辑的多轨 MIDI 草稿。

## 当前状态

规划阶段。尚未实现转录程序、安装模型或完成音频实测。

首版优先验证功能，不开发前端。候选路线是直接多乐器转录，以及先分离音频再分别转录；用同一批素材比较后再确定方案。

每个可用里程碑完成验证后提交并推送；重要版本添加版本标签。
