# 鼓强化版：当前约60秒片段

本轮只优化鼓。钢琴固定B，木吉他、电吉他、贝斯、弦乐保持上次版本；忽略人声。没有读取60–120秒结果来调参，没有训练模型、调用付费API或上传用户音频。

## 实测结果

输入为用户提供的AudioTrimmer MP3，解码60.0304375秒，SHA256为`6da0f0ec87ee0b37d83d1c8fc2aa8f89dec1cb38b5c1926484317ac91c5bab98`。

评分比较的是与用户指定改编MIDI的一致度：同鼓件GM编号、起音相差不超过50毫秒、每个事件只匹配一次。全部方案共用标准时间=预测时间×0.9995+0.14秒，标准窗口[0.14,60.14042228125)。不为每个方案重新搜索时间偏移。

最终精确率86.02%，召回率85.11%。F1比上版增加8.31个百分点。六轨合成仅替换鼓，整体383匹配/545预测/494标准，F1为73.72%；其余五轨的原始MIDI消息及时间刻度逐项相同。

这是一段已经多次看过答案的开发样本。阈值和整套规则通过开发分数选择，存在过拟合风险，85.56%不能称为新歌曲正确率。标准是改编版，也不保证逐击对应原录音。没有进行人工听辨、Logic实机验收或独立新歌验证。当前F1不评价力度、音色、延音或整曲音乐性。

## 最终实现路径

全局流程：原音频 → 已验证的Demucs / SW分离和原混音预测 → 各模型转谱 → 固定鼓件来源和模型一致性过滤 → MIDI → 采样库试听。原混音能保留部分分离后漏掉的ride；分离轨减少其他乐器干扰。两者互补。

| 鼓件 | 固定路线 |
|---|---|
| 底鼓36 | SW鼓＋OaF阈值0.5；Demucs＋YourMT3同键±30ms支持才保留 |
| 军鼓38 | SW＋ADTOF阈值0.18；Demucs＋OaF阈值0.35同键±50ms支持才保留 |
| 闭镲42 | SW＋ADTOF阈值0.165 |
| 高通鼓48 | SW＋OaF阈值0.5 |
| ride51 | 原混音YourMT3；SW＋ADTOF粗镲类49阈值0.15、±30ms支持才保留 |
| splash55 | Demucs＋YourMT3；ADTOF粗镲类49阈值0.225、±30ms支持才保留 |
| 其他编号 | 保持Demucs＋YourMT3原输出 |

粗镲类只作为“附近是否确有一次镲击”的支持证据，不能判断ride或splash。最终仍用原预测的GM编号、时间、力度，不把49改成51，不把35改成36。支持采用按起音顺序的贪心近邻，每个支持事件最多用一次；它不是最大匹配算法。评分使用独立的最大一对一匹配。

`audio_midi.drums.optimized_drums_v2`固定上述规则。`scripts/build_drums_v2.py`通过原MP3及每个缓存文件哈希重建，已实测与最终鼓MID字节一致。该入口只重建缓存，不会自动为任意新歌运行全部模型。前端、全新音频一键生产、商用模型许可仍未完成。

## 尝试过什么

实际新增13次受资源上限约束的模型进程尝试：OaF 3次；YODO 7次（4次适配器失败、1次15秒探测及2次全片成功执行）；IDM 3次。每次最多2线程、6GiB、1800秒，同一实现最多自动重试一次。探测取当前片段前15秒，不涉及历史60–120秒。

OaF是第三方ONNX转换，原模型输出8类；与原TensorFlow版的数值等价性未独立复现。全片两种源模型阶段约1.49/1.22秒，峰值约0.49GiB，不包含此前的分离耗时。单独全套替换较差，只有部分鼓件适合融合。

YODO原作者11类权重通过CPU OpenCV运行。先后修复了FFT精度和输入通道适配错误，失败4次也计入预算。修正后两种全片源都没有达到0.20候选门槛的检测，不能加入最终版；尚未用阳性样本或原Darknet验证适配器，所以不能据此断言作者模型本身差。

IDM使用官方预训练encoder严格加载，9类输出，不调用人工起音覆盖或参考合成。SW/Demucs全片约2.09/1.82秒，峰值约0.62/0.61GiB。单独69%左右；尝试替换缺失的开镲/crash没有净提升，最终不采用。阈值0.7的两项为零事件，保留为空MIDI对照，生产导出仍拒绝空结果。

共记录188个评分候选，其中129种不同的MID字节结果；这是阈值与组合数量，不是188种模型。候选生成脚本不读取标准，评分脚本独立读取标准。开发选择按完整参数或完整鼓件规则进行，没有照标准逐音拼接。

已有API凭据文件仍为空，未进行远程实验。Omnizart官方ARM兼容限制使其未在本机运行。这些未跑方案不列入本曲名次。

## 交付与复现

`outputs/runs/drums-v2/交付/`包含最终鼓MID与WAV、仅替换鼓的六轨MID与WAV、9个额外代表方案的MID/WAV，共11段试听，以及188个候选MID和逐项评分。试听为GeneralUser GS从MIDI离线渲染，没有混入原曲。已生成文件但没有在用户电脑播放。

本地重建示例：

```sh
.venv/bin/python scripts/build_drums_v2.py '/Users/ringscherry/Desktop/吉他产品/v0.0/test/李荣浩 - 不将就-[AudioTrimmer.com].mp3' --manifest outputs/drums-v2/固定鼓来源清单.json --duration 60.0304375 --output work/drums-v2/新建鼓.mid
```

缓存、输入音频、权重与试听均不上传Git。来源、模型阶段耗时、产物哈希和独立审查记录随代码存档。依赖ADTOF非商业研究组件及SW权重，不能直接视为商业产品授权。
