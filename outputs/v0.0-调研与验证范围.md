# v0.0 调研与验证范围

日期：2026-10-15
状态：范围建议，未实施或进行音频模型实测。

目标：本地音频或视频文件 → 按乐器分组、可在音乐制作软件内编辑的多轨 MIDI 草稿。

建议首版：15–60 秒片段；WAV/MP3/M4A/FLAC 与 MP4/MOV；按实际解码能力校验，建议 100 MB 上限；不处理分享链接。人声保留音频，旋律转录先作实验。鼓只验证基本类别，复杂技巧暂不承诺。成功输出只包含实际识别的轨，不凑空轨。

流程：校验与提取音频 → 统一时间轴 → 可替换转录路线 → 音符整理 → MIDI 与项目数据导出 → 试听与质量报告。

路线：A 用 YourMT3+ 类多乐器模型直接转录；B 用 Demucs 类模型分离，再以 Basic Pitch 或专用模型分别转录。两路线用同一批素材对比，暂不选定生产路线。Basic Pitch 不能替代鼓转录，也不能自动完成乐器分轨；other 分离音轨仍可能含多乐器。

输出：多轨 MIDI（建议 Type 1）、每轨 MIDI、project.json、试听 WAV、report.json；若执行分离则另存 stems 音频。项目数据保留原始时间、音符、轨分组、模型版本、参数及警告。MIDI 不包含原声音色、插件或完整 DAW 工程。

异常：损坏/无音轨/静音拒绝；过长或过大明确提示裁剪，不静默截断；多音轨视频要求选轨；复杂混音及低质音频输出警告或部分成功；显存不足缩短分段并有限重试；所有片段保留时间偏移与重叠处理；识别不到音符不报成功；不强制量化自由节奏，也不把默认 BPM 当识别结果。

验证：首批建议 20 段，每类 5 段：独奏、简单合奏、目标流行歌曲、困难/异常素材。合成 MIDI 配对音频用于客观音符检查，真实歌曲用于主观与编辑耗时检查。竞品在用户授权上传及消费额度后再同素材对比。建议工程可导入率 100%；可用性门槛需先定义，再根据首批实测确认。记录完整耗时、峰值内存/显存、单分钟成本与人工修改耗时。

公开来源：
- https://lingpu.cn/ ：首页产品描述，非真实转录测试。
- https://github.com/spotify/basic-pitch ：官方说明一次处理一种乐器效果最佳。
- https://github.com/facebookresearch/demucs ：六类分离及钢琴分离局限；原仓库归档。
- https://github.com/mimbres/YourMT3 ：官方研究实现与演示入口。
- https://arxiv.org/abs/2407.04822 ：多乐器转录研究及流行音乐局限。
- https://github.com/magenta/mt3 ：直接多乐器转录基线。
- https://ffmpeg.org/ffmpeg.html ：音视频流选择与转码。
