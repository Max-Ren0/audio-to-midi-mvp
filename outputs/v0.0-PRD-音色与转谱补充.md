# v0.0 PRD 补充


## 新增需求：乐器分配、音色试听与质量优先重转录（2026-10-15）

### 产品目标

MIDI导入音乐软件后，各轨应带有明确的乐器类别、通道与标准音色编号，尽可能由播放器自动匹配乐器；另交付基于采样音色库合成的试听音频，让用户在不配置音源的情况下检查音乐是否可辨认。

### 文件格式与交付边界

- 标准 `.mid` 保存音符、通道、Bank Select及Program Change等演奏指令，不能内嵌真实乐器音频、插件或Logic音色库。禁止将写入GM编号宣传为“已将真实声音装进MIDI”。
- MIDI必须按类别独立分轨，轨道名称可识别；各轨在首个音符前写入明确的音色选择。鼓使用第10通道及GM打击乐映射，其余轨使用独立非鼓通道。
- 默认乐器（0基GM编号）：钢琴0、木吉他25、电吉他27、贝斯33、弦乐48、人声旋律53；人声53是合唱音色近似，不能还原李荣浩或任何原唱声音。
- 所有音符放在一条共享时间线上；不得通过错误移调、填满七轨或套用原唱音频伪造MIDI效果。
- 附带 `试听.wav`：由所交付MIDI配采样音色库离线合成，不混入原曲或分离音频。记录所用音色库、版本及限制。
- Logic是否自动建立正确软件乐器取决于打开/导入方式、音源和版本。仅写入GM信息不能保证任意Logic工程自动配好内置音源，未经实机检查不得宣称保证兼容。
- 如果还需保留音源插件、混音和真实采样设置，应另立Logic原生工程或“工程+音色库”交付要求，不能用一个.mid替代。

### 重转录与质量验收

- 使用用户本轮提供的AudioTrimmer MP3，原文件保持不变；本地处理，不自动上传第三方。
- 按“先分离声音、再分别转谱”的路线做对照实验；七类仍为目标，不合并或伪造木/电吉他标签，未能可靠拆出的类别明确报告。
- 用户已明确选择质量优先，允许本轮实验超过原三倍时长。实验单独记录耗时，不能据此声称原三倍时长指标已达成；默认生产模式不静默改变时间限制。
- 将转谱质量和音色播放分别检查：独奏主旋律能否辨认歌曲、单轨是否与原声对应、合奏是否有明显错音堆叠；音源更真实不能掩盖音符错误。
- 交付MIDI、直接由它合成的试听音频、各轨乐器对应表及未解决问题。未经标注不报告准确率，也不把多轨文件可打开当作音乐质量通过。
