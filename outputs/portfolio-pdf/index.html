01 / 产品定位

一份能核对的练习草稿。

想跟流行歌练贝斯、鼓或钢琴的学习者，常从一首混音开始。缺谱时，他们可能要降速循环，在听不清的几拍反复核对。

不敢信，要从头听一遍。
改不动，音符对不上小节。

围绕这两个假设痛点做了技术验证，尚未证明解决了用户痛点。

方向 A

可信的三轨草稿

评测口径已公开，回执记录轨道状态与音符数。存在判断默认关闭，可信度和用户提示留待未来版本。

方向 B

降低编辑成本

输出 GM 鼓键，评测只计底鼓与军鼓。小节对齐默认关闭，真实 3/4 拍和音乐软件导入待验。

北极星指标

真值集逐轨 F1

按独立真值衡量钢琴、贝斯、鼓的漏音和误报，用于上线验收。

03 / 一键流程

只输入 MP3，即可运行。

2026-11-25 已实现本地一键三轨入口。各阶段直接使用音频和本次中间产物，整体成功后再发布 MIDI 和回执。

01

检查输入

校验格式、时长和模型资源。

02

生成基线

YourMT3 从混音识别乐器和音符。

03

细化钢琴

基线识别出钢琴时才运行专用路线。

04

补充贝斯和鼓

从原混音重新转写，再逐轨补充或替换。

05

导出 MIDI

合并轨道，并写入运行回执。

04 / 流程验收与可选功能

流程验收（冒烟测试）

8 段覆盖三轨齐全、缺贝斯、缺鼓、纯钢琴，全部跑通并输出可读 MIDI；同时发现缺轨时会误报。质量评测见 RWC-P 50 首。
冒烟测试报告 ↗

11-25 实测 · 默认串行

并行耗时约少 20%

两个 60 秒片段串并行输出一致。并行更占内存，收益随片段和设备变化。

11-27 实测 · 默认关闭

小节线 F1 7.74% → 49.54%

50 首对比固定 120 BPM。相对上一版对齐，倍速 6 → 0 首，半速 1 → 2 首，小节线增幅未达显著。真实 3/4 和音乐软件导入待验。

11-26 实测 · 默认关闭

空类别误报 1065 → 215

23 段中的误报音符减少，但误删 3/36 条真实轨。另一批 RWC-P 测试也发现真实稀疏声部会被删除。

06 / Verification & Versioning

每个结论，都要经得起别人复查。

每个候选版本先冻结成 Git 提交，再交给一个独立 Agent 只读复核。复核者不改文件，也不默认作者的结论是对的；发现问题就修复、再冻结、再复验。

1

冻结版本

提交代码与结果，记录提交号和结果文件哈希。

2

独立复核

另一个 Agent 只读检查评分逻辑、输出文件和边界情况。

3

修复问题

逐条判断复核意见，确认成立的就修复。

4

复验后发布

只复查改动部分，通过后合并、打标签、上线。

回归验证：2026-11-27 的 public.15 记录为 243 项通过、2 项跳过。用于检查实现回归，转写质量另见评测。 版本记录 ↗

证据复查：冻结划分和评分口径后再运行封存测试。历史复核曾发现训练重叠证据表述过强、续跑误判完成状态，均已修正。
