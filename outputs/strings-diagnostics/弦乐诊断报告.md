# 贝斯冻结与弦乐诊断

2026-10-17。本轮只诊断，不改任何已有MIDI或运行新模型，不访问60–120，不操作用户界面。贝斯明确冻结为D75+W64（77.33%严格开发分），版本v0.1.0-bass-sequence.1；config/bass-frozen.lock.json绑定原锁、标签提交、选用贝斯/六轨及8实现文件SHA。该冻结是研究路径和产物约束，没有虚构任意新歌生产CLI。

## 当前弦乐处理地图

原MP3 → SW BS-RoFormer六源分离中的other.wav → 转单声道16k → YourMT3 yptf_moe_nops → 原事件配对/跨块衔接 → 只保留模型判为strings的类别 → 去短音/同音重复/重叠整理 → GM48 String Ensemble MIDI → GeneralUser GS合成试听。

other是残余声部，不是专门的弦乐分离。对应scripts/run_v01.py、src/audio_midi/backends/selected.py、quality.py::assemble、stitching.py::clean_notes。当前SW输入strings.npy与other.wav按已实现的resample_poly重建逐样本相同；SW原39音通过现有清理和MIDI导出与当前B文件字节相同，且与最新六轨弦乐音高/时序一致。旧Demucs A亦从原JSON重建MIDI字节相同。

比较参考是用户确认来自同一MP3的高相似度提取MIDI，不是原工程/录音室真值。文件名仍保留，不因带“改编”推断人工重编。当前0–60秒参考只有7个弦乐起音：约6.976–10.320秒的两个MIDI79长音；10.320–12.000秒的MIDI72长音；12.000–13.652秒的57/60/65/67四音和声。后续片段不纳入。

后3项在固定对齐的整个0–60.0304375秒区间逐段计算集合交并，用“音高×持续秒数”而非音符颗数，合并切分/重复同音对结果无影响；音级指标把八度合并，有声指标进一步不看音高。它们是新增客观诊断，不是已校准的听感相似度或替代严格评分的统一验收，不可把79.11%解读成79%还原度，也不应拿不同指标横向比“提升”。没有为任何候选重新拟合对齐。

结论：当前大致在参考发声的时段发声，但音高/和声内容差异明显；问题不是把起音再微调几十毫秒。单看严格F1从10.26到13.04也不能证明所有音乐维度都更好，A的持续音级重合反而略高。

## 四个具体问题与证据

1. **高音持续声部缺失。** 当前B在两个参考79长音的时间内，同音高持续覆盖均为0%；72长音覆盖95.8%。不能只用统一八度修正，因为并非所有目标都低了同一八度，音级重合也只有41.34%。
2. **和声被切碎/错识别。** 参考四音和声的同音高持续覆盖：57=41.1%、60=32.0%、65=41.0%、67=36.8%。当前B有15个<150ms音符，并有一串23个快速上行音，从约12.410秒的57走到13.880秒的96。它存在于原JSON，清理导出没有制造它；可能是真实其他声部、模型误判或解码异常，不能凭外形断定“幻觉”，也不能直接删掉。
3. **跨块延音值得优先排查。** 模型窗口32767/16000=2.0479375秒。原B有10音恰好结束于分块边界（包括12.287625秒截短的4个和声音），记录missing_tie14、note_off_without_onset22。原A弦乐也有15个边界结束音。事件配对层在缺tie时按窗口起点关闭已有音，这与短截信号相符；没有保存原始token/tie事件，尚不能确认模型漏tie还是代码协议问题，更不能把参考结束时间拿来补长。
4. **声源和乐器身份仍不可靠。** SW原始JSON共39音，全部被模型标成strings；后置类别筛选并没有进一步挑出真实弦乐。旧A的other原输出含332钢琴、78弦乐、39人声、19贝斯，证明这一输入路线允许多类内容。当前B有约27.4%的预测“音高秒”与参考钢琴同音高同时出现，但钢琴/弦乐可能真实重奏，这只能作为串音排查线索，不能证明27.4%都是钢琴误报。无录音室独立弦乐WAV，不能算SDR或确认实际声源。

## 下一步建议顺序（本轮未执行优化）

1. **先给跨块衔接补证据。** 在当前固定模型上保存窗口原始token、note_on/off、tie和配对理由；用合成长音跨块控制与同一短段回放比较上游官方协议。发现确凿问题再修，不能按参考逐音延长。
2. **再验证音源是否含目标弦乐。** 对两个79长音和四音和声，检查原混音、两个other源、分离的钢琴/吉他源；结合局部听辨和声学证据区分“源中丢失”与“转写漏掉”。再决定专门弦乐分离/存在性检测或多来源策略，不声称现有other已是弦乐。
3. **最后比较适合持续、多音和声的转写。** 先得到稳定的同时音高与延音，再定位起音；不能照搬贝斯单音pYIN路线，也不能一刀切删除快音。固定少量完整候选，用持续音高/音级/声部时段指标、严格F1和统一音色试听并列比较。
4. 继续保持贝斯、钢琴B和鼓冻结。0–60是开发片段，参考只有7个弦乐音，后续必须跨片段/跨歌曲验证，不能凭这7音宣称弦乐方案达标。
