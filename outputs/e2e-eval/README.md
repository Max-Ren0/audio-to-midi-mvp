# Noto 一键三轨端到端评测

只输入音频，**8/8 段生成有效 MIDI**，钢琴、贝斯、鼓的 micro F1 分别为 **94.74%、54.79%、49.80%**，相比同批条件评测分别变化 **+0.00、-8.92、-0.94 个百分点**。

## 1. 数据与打分

- **BabySlakh** 按编号从小到大取既有清单中 `contains` 同时含 `piano`、`bass`、`drums` 的前 3 段，得到 `slakh-Track00001`、`slakh-Track00002`、`slakh-Track00003`。另加 `slakh-Track00017`（参考无贝斯、无钢琴）和 `slakh-Track00018`（参考无鼓）。每段取 Slakh2100 train 的 30–90 秒合成混音窗口。
- **MAESTRO** 使用官方 test 的 `maestro-01`、`maestro-02`、`maestro-03`，均为真实原声钢琴整曲。
- 使用主检出既有的 `outputs/runs/multi-song-eval/items/`。运行阶段只把每段的 `input.mp3` 交给 `scripts/run_noto.py`。钢琴 B 由基线是否识别出钢琴轨触发，MuScriptor 使用固定的候选乐器设置。评分阶段才读取由参考 MIDI 转换得到的 `reference.json`。
- 复用多曲评测的音符匹配逻辑。同类别、同音高、起音误差 ≤ 50 ms，一对一匹配；鼓要求同一 GM 键位。BabySlakh 的贝斯参考沿用原口径降一个八度。最终 `noto.mid` 中钢琴、贝斯、鼓的全部音符参与评分，参考中不存在的类别所产生的音符全部计作误报。研究轨只统计音符数。
- 成功要求退出码为 0（如退出码有记录）、回执为 `ok` 且有最终 MIDI。失败按零预测计分，参考音符全部计为漏报。若发生重试，保留各次记录，主表取最后一次成功，否则取最后一次尝试。

## 6. 局限

- 仅 8 段。BabySlakh 是合成混音，MAESTRO 是独奏钢琴，尚无真实多轨混音验证。
- BabySlakh 取自 Slakh train，与 YourMT3 本地训练数据预设存在划分重叠，实际权重是否见过这些样本未逐一核实。MAESTRO 的三首录音是否被各模型见过也未核实。
- BabySlakh 的参考 MIDI 来自合成分轨，钢琴类别涵盖电钢、羽管键琴等音色，鼓包含架子鼓之外的打击乐。不同 GM 键位计作不同音符。MAESTRO 参考来自配对的演奏 MIDI，沿用此前的对齐和转换，未逐音人工校对。
- 这里只检查类别、音高与起音。听感、时值、力度与人工修改时间仍待评估。

## 7. 复现

从本仓库根目录运行。先将 `NOTO_RESOURCES` 设为持有既有数据、模型和 Python 环境的主检出目录，将 `NOTO_E2E_RUNS` 设为仓库外的私密运行目录。脚本串行执行，每首命令使用 `nice -n 10`，已成功样本可跳过，失败重试使用新目录。 [一键三轨前置资源](../../README.md#一键三轨)

```sh
export PYTHONDONTWRITEBYTECODE=1 GIT_OPTIONAL_LOCKS=0 PYTHONPATH="$PWD/src"
"${NOTO_RESOURCES:?请设置 NOTO_RESOURCES}/.venv/bin/python" outputs/e2e-eval/run_e2e.py \
  --resources "$NOTO_RESOURCES" --runs "${NOTO_E2E_RUNS:?请设置 NOTO_E2E_RUNS}"
"${NOTO_RESOURCES:?请设置 NOTO_RESOURCES}/.venv/bin/python" outputs/e2e-eval/score_e2e.py \
  --resources "$NOTO_RESOURCES" --runs "${NOTO_E2E_RUNS:?请设置 NOTO_E2E_RUNS}"
```

打分脚本读取私密回执、最终 MIDI、参考标注和既有条件评测结果，重算报告数据。 [results.json](results.json)
