# Noto 竞品对比与产品规划

## 1. 一句话结论

**Noto 值得验证的差异不是“也能导出多轨 MIDI”，而是让用户更快拿到能继续改编的钢琴、贝斯、鼓三轨草稿：与 Audio Jam 的分轨跟练相比，交付物不同；与灵谱、RipX、NeuralNote 相比，可用性优势尚未证实，最大短板是缺少真实多轨录音的端到端验证和人工修订时间数据。**（推断；[A1][A2][L1][R1][N1]；Noto 范围见 [P]）

NeuralNote v2 与 Noto 贝斯／鼓替换路线使用同一模型家族，不能把模型本身当差异；应比较按乐器组合多模型（如钢琴用 Transkun）、评测口径和交付流程。（调研＋推断；[N2][N3][P][P-M]）

Noto 当前是本地研究原型：已有实验 MIDI，可用外部音乐软件编辑，尚无内置编辑器，也没完成任意歌曲一键转写的三轨验收；吉他和弦乐是研究项，人声不纳入输出验收。首轮多曲对比是按参考乐器列表选轨的条件评测，不代表用户直接丢进一首歌就能得到同样的结果。见 [P]。

## 2. 竞品一览

**参照选择：**Moises 用来对照“分轨后反复练习”；RipX 用来看专业制作如何校音、纠错和导出；NeuralNote 用来看本地转写、按乐器试听和接入 DAW（数字音频工作站），后两者还有仓库样本可核对。三者分别补充使用频率、编辑深度和工作流入口，而不是给同一项准确率多列几家。（推断；[M1][M2][R2][N1]；[实测 R][实测 N]）

此处“音频分轨”是把原录音拆成可单听的声音轨；“多轨 MIDI”是把音高、起点、时值等记成可改的音符，并按乐器组织。分出鼓声不等于识别出每次击鼓。“可编辑”也不等于产品有内置逐音编辑器。F1 同时反映错报和漏报，不是听感评分。表中来源代码对应第 7 节 URL，公开页面均于 **2026-11-24** 查看；实测是仓库旧记录，不是本轮跑测。用户画像是用途推断。

## 3. 逐个竞品

### Audio Jam｜用户想把某一句弹下来

- **核心路径（调研）**：导入本地音视频、受支持的链接或录音 → 分离目标乐器 → 单独听它，或静音它用其他轨作伴奏 → 看和弦、设 A/B 区间、降速并跟练。教程列有录音和链接两种入口，未据此推断所有平台都能导入相同链接。[A2][A3][A4]
- **商业与增长（调研／推断）**：免费下载安装，靠 Pro 订阅转化；官网用分轨试听、乐手展示和教程说明用途，云同步和书签可以让用户下次接着练（留存动机为推断，不是经营数据）。美区商店把 $6.99 标成**周付**而不是 `CONTEXT.md` 交接写的月付，当前可见的月付条目为 $12.99；年度多条目不能写成全国统一价或保证可买价。[A1–A5]；历史 [P]
- **AI 边界与启示（调研／推断）**：官方描述的是音频分离、和弦、节拍；导入并预览 MusicXML/GTP 不等于从录音生成乐谱，官方宣传的准确率也不是 Noto 的逐音符 F1。Noto 可借用“单独听一轨、循环听错音”来降低校对成本，但别先做一整套练习功能。[A1][A2]

### 灵谱｜最直接的产品对手

- **核心路径（调研＋历史实测）**：首页可搜歌名、贴抖音／小红书／B 站分享链接，或从文件进入。首页的时长提示在搜索／链接区域，为不超过 30 分钟，未独立核实所有上传方式共用此限制。进入工程后可切换看谱方式、校音并选轨导出。2026-10-15 的《不将就》编辑页检查看到八条可见轨，下载面板显示 `.mid` 完成；菜单操作会自动复制工程。它证明旧版流程走到下载，不证明该 MIDI 与参考文件相同，也不证明可见轨都是自动生成。[L1]；[实测 L]
- **商业、增长与留存（调研／推断）**：按转录时长充值，按秒扣费，转录失败退回；公开前端文案列有会员和体验包，首页说明新用户注册送 10 分钟转录额度，具体价格未见。[L1][L2] 广场把试听、看谱、收藏提前，推断能让新用户先看到成果，再决定是否转自己的歌，收藏为回访提供理由。交接摘要记载有微信群入口，本轮没确认群活跃和转化，也没进群。不能假设广场内容都是机器生成，更不能用广场中的《唯一》作为首次自动结果。[L1][P]；[实测 L]
- **AI 边界与启示（实测／未知／推断）**：编辑页版本历史当时读取失败；现成 MIDI 也能进入工程。模型、分离顺序、是否人工修谱及木电吉他的区分质量均未知。相同的产品表达不足以差异化，Noto 更应该验证“哪一轨可以直接用、哪里值得听一遍、从拿到草稿到导出成品花多久”，并清楚标注自动稿与人工修订稿。[L1]；[实测 L]

### RipX DAW｜看识别出错后怎么救

文件导入 → 分层、独奏试听 → 把错归层的音符移走或删掉 → 选层导出 MIDI；付费分标准与 PRO，用试用、教程和 Discord 降低上手门槛。（调研 [R1–R5]）仓库样本存在多轨 MIDI；固定旧时间映射下器乐 F1 为 **2.07%**，但只测一首的片段，导出时间原点未验证，参考是指定改编版，也未取得分层 WAV 做同转谱器对照。不能据此宣称 Noto 更准，或把低分全归因于音频分离。启示：先保证时间原点清晰、轨道可纠正，再谈改编效率。（实测＋推断；[实测 R]）

### NeuralNote v2｜看如何接上创作者现有流程

拖音频或录音 → 手选乐器或自动识别 → 边转写边用卷帘和原声混听 → 保存 MIDI 或拖入 DAW。软件免费，GitHub 开放问题反馈；“不用切换工作环境”是留存推断，而非已公布的指标。（调研＋推断 [N1][N2]）仓库样本于 **2026-11-05** 评测（提交 `0297c4d`），旧对齐口径下整体 F1 为 **25.11%**。评测晚于 **2026-10-04** 的 v2.0.0 发布，且导出带乐器分类，推断可能来自 v2／MuScriptor；版本、所用权重和设置未确认，单曲参考也不是录音室真值，不能把这个分数当作 v2 的普遍表现。（实测＋推断；[实测 N][N3]）

**对 Noto 的启示（推断）：**两边的贝斯／鼓路线同属 MuScriptor 家族，引擎同源于 `muscriptor.cpp`，不等于权重、配置或输出一致。可验证的差异在按乐器组合多模型（如钢琴用 Transkun）、统一逐轨评测口径，以及用户从试听、修订到导入 DAW 是否更省时间；不把“离线＋MIDI”或贝斯／鼓模型当独占卖点。[N2][N3][P][P-M]

### Moises｜看练习用户为什么回来

导入 → 选分离方式 → 调音量、循环、变速，跟着伴奏练习或导出音频；套餐区分分离权限和练习工具，曲目库和歌单可承接重复使用。Live 是实时分离，不代表实时逐音符识别。启示：如果研究发现用户做完第一次分轨还会反复回听，同一曲目保留练习状态有价值；不要把这类回访误当作用户想付费导出 MIDI 的证据。（调研＋推断 [M1–M5]）

## 6. 低成本验证（计划，尚未执行）

1. **公开样例做两种检查。** 先只看已有官网示例，记录导入、试听、编辑和导出路径；成品只用于体验拆解。准确率要用有授权且有参考 MIDI 的同一片段、保留未经编辑的首稿，统一时间原点、乐器映射和仓库已有的起音匹配口径，并记是否给了参考乐器名单。**要主人同意**：选材和新增下载、本地运行；本轮不登录、不上传，也不把公开可听当成授权。若竞品必须提交素材才出首稿，本方案将其记为不可测，不以广场成品代替。
2. **访谈＋人工任务计时。** 请扒谱、翻弹或编曲者回忆上次实际做的歌：“从哪里找音？在哪一步卡最久？哪些错音让你宁愿重做？怎样算能交付？”在已授权片段上比较手工与自动草稿两条路径，交替做题顺序，记等待、返工和中途放弃。**要主人同意**：招募范围、是否录音和匿名引用方式；默认只记匿名笔记，不外发素材。
3. **公开评论归类。** 对美区 Audio Jam 和 Moises 商店公开点评按固定时间窗记录练习收益、导入失败、订阅抱怨、准确率和导出阻力，低评高评都看，记录反例；不把样本占比当市场比例。灵谱广场只能看用法和作品呈现，不能替代用户评价。**要主人同意**：仅当需要公开引用可识别原话或对外联系评论作者；只读匿名归类可直接做，不发帖、不抓私域。[A5][M4][L1]
